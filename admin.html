Comment créer le token
1. Sur GitHub : photo de profil, Settings, tout en bas à gauche Developer settings.
2. Personal access tokens, Fine-grained tokens, Generate new token.
3. Nom libre, expiration au choix (par ex. 90 jours).
4. Repository access : Only select repositories, puis choisis cyberware-editor.
5. Permissions, Repository permissions, Contents : Read and write.
6. Generate token, copie-le tout de suite (il ne s'affiche qu'une fois) et colle-le ci-dessus.
